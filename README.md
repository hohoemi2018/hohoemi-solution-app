# ほほえみシナリオノート

ブレインジム101講座の受講生が、例外探しとコンプリメントを使った会話を練習するためのアプリです。場面を入力すると、相手に合わせたロールプレイの会話例を作ります。

## はじめかた

Node.js 18 以降が必要です。外部パッケージのインストールや API キーは必要ありません。

```sh
npm start
```

起動後、ブラウザーで表示された URL を開いてください。`PORT` と `HOST` 環境変数で待ち受け先を変更できます。

```sh
npm test
```

会話例は入力内容をもとにブラウザー内で組み立てます。生成 AI や外部サービスには送信せず、保存もしません。相手の返答は練習用の例であり、実際の会話では相手の言葉に合わせてください。

画面のフォントには Zen Maru Gothic を使用しています。ライセンスは `assets/ZenMaruGothic-LICENSE.txt` に同梱しています。
